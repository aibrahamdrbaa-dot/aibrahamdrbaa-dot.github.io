
# Shared Prompting Core

## 1. Start with the artifact

Name what the final output is: real-estate listing hero, editorial portrait, product campaign, poster, infographic, architectural visualization, storyboard frame.

## 2. Lock composition before decoration

Specify only the spatial decisions that matter:
- subject position;
- foreground/midground/background;
- horizon;
- negative space;
- grid/panel structure;
- text placement;
- viewpoint.

## 3. Translate adjectives into mechanisms

Instead of "premium cinematic", describe visible causes such as soft directional light, controlled highlights, readable shadow detail, and restrained color.

## 4. Subject integrity

For people, products and buildings:
- define identity anchors;
- preserve distinctive geometry;
- never invent brand markings;
- for edits, state what must remain unchanged.

## 5. Camera language

Use terms only when they change the result: eye level, low angle, overhead, three-quarter view, wide-angle perspective, compressed telephoto perspective, macro, locked-off, push-in, whip-pan, dolly, over-the-shoulder.

Avoid fake precision. Describe the visual effect when exact camera values are not important.

## 6. Lighting

Useful axes:
direction, hardness/softness, temperature, contrast, key/fill/rim relationship, reflections and practical sources.

## 7. Materials

Pair materials with light behavior: natural oak, honed stone, linen, glass, matte ceramic, brushed metal, wet asphalt.

## 8. Constraints

Use explicit constraints for things the model tends to improvise:
exact text, number of panels/objects, preserve building geometry, no extra furniture, no people, no visible logos, no perspective change.

## 9. Prompt economy

Remove details that do not change the output. Keep details that resolve ambiguity, preserve identity, control spatial relationships, control visual treatment, or enforce literal copy.

## 10. Iteration loop

1. broad composition
2. structural correction
3. targeted polish
4. final cleanup

Change one logical variable per iteration when possible.

## 11. References

Give each input a job: subject identity, pose, style, environment, product shape, or layout.
