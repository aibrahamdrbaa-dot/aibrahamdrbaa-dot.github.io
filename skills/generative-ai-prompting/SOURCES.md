
# Research sources

Checked on 2026-09-23.

## Official — primary

### Google DeepMind — Gemini Omni prompt guide
https://deepmind.google/models/gemini-omni/prompt-guide/

Used for the five core Omni prompt decisions, camera/framing/motion, style, lighting, location, action, iterative editing, storyboards and continuity.

### Google AI for Developers — Gemini Omni API
https://ai.google.dev/gemini-api/docs/omni

Used for the current model identifier, image-to-video, video editing/extension, first/last-frame workflows and text-in-video.

### Google AI for Developers — Nano Banana image generation
https://ai.google.dev/gemini-api/docs/image-generation

Used for current Nano Banana model mapping, image prompting examples, references, multi-turn editing, text rendering and current limitations.

### OpenAI — ChatGPT Images 2.5
https://openai.com/index/introducing-chatgpt-images-2-5/

Used for current Images 2.5 capabilities and Flare/Sunburst positioning.

### OpenAI — GPT Image 2.5 prompting
https://developers.openai.com/api/docs/guides/image-prompting

Used for current prompt structure and targeted edit/invariant guidance.

### OpenAI — Image generation API reference
https://developers.openai.com/api/reference/cli/resources/images/methods/generate

Used for current GPT Image model IDs, prompt length and background support.

## Selection decision

The package core follows provider documentation first, then maintained model-specific skills, then curated community libraries. Third-party prompt bodies and images are not republished as package-owned content.
