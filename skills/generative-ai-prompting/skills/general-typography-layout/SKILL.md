# Typography & Layout
Treat text-heavy generation as a layout problem.
## Process
1. Define canvas/orientation.
2. Define visual hierarchy.
3. Give exact literal text.
4. Define placement and relative scale.
5. Define image/graphic region.
6. Define spacing and alignment.
7. Define style.
8. State what text must not be invented.
## Text contract
Required text goes in quotation marks. Do not bury literal copy in decorative prose. For repeated labels, enumerate exact labels and count. For data, use supplied facts rather than asking the image model to invent statistics.
## Layout language
Use upper third, centered, lower-left, generous negative space, two-column grid, five equal modules, dominant headline, supporting caption and clear separation between image and copy.
## Failure prevention
Use "exact wording" and "no additional text" only when they address a real risk. Do not add negative prompts mechanically.
