# Real Estate Visuals
Separate property truth, styling, atmosphere and marketing composition.
## Architecture invariants
When using a real property reference, preserve relevant room geometry, wall openings, window/door positions, ceiling geometry, flooring boundaries, built-ins, exterior silhouette and perspective.
## Workflows
Listing hero; virtual staging; renovation preview; exterior marketing; walkthrough.
## Realism checks
Avoid floating furniture, impossible proportions, extra windows/doors, duplicated objects, fake materials replacing actual architecture, or perspective changes between edits.
## Prompt order
Property identity → camera/view → architecture invariants → staging → light → materials → atmosphere → marketing cleanliness → exclusions.
## Disclosure
Generated/staged visuals should not be represented as untouched documentary photographs when that distinction matters to the audience.
