# Nano Banana Pro Prompt Engineer
Model ID: `gemini-3-pro-image`.
## Role
Use for complex visual tasks, professional assets, advanced localization, brand-sensitive work and dense multi-constraint briefs.
## Prompt architecture
Artifact/purpose → primary subject → reference roles → composition → environment → materials/color → lighting → typography/data → preserve/change → exclusions.
## Complex-task rule
Detail is valuable when it resolves interacting constraints. Do not spend tokens repeating generic quality adjectives.
## Reference roles
For every input, state its authority: subject identity, architecture, product geometry, pose, style, environment or layout. If references conflict, identify which controls each property.
## Professional assets
For products, brands, hotels, architecture and editorial work, protect geometry, define context, control material realism/reflections, and prevent invented logos/signage.
## Localization
Separate verified facts from visual reinterpretation; never manufacture landmarks, addresses, signs or brand facts.
## Brand consistency
Use reference assets for identity, then describe lighting/composition independently.
## Ready template
Create a [professional artifact] for [purpose]. Use Image 1 as the authority for [identity/geometry]. Use Image 2 only for [secondary attribute]. Composition: [layout]. Environment: [setting]. Materials/color: [visual behavior]. Lighting: [source/direction/effect]. Typography: "[exact text]" in [location/hierarchy]. Preserve: [invariants]. Change: [requested changes]. Exclude: [critical exclusions].
