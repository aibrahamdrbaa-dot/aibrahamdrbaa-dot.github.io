# Security

MANIAC is a static storefront. The repository intentionally contains no server-side credentials, payment secrets, API keys, or user data.

## Reporting a vulnerability

Please do not publish sensitive security findings in a public GitHub issue. Send the details privately via Telegram at @aabrahamdrbaa.

Useful reports include:
- affected page or file
- reproducible steps
- expected vs. actual behavior
- security impact
- screenshots or a minimal proof when safe

## Scope

Security work covers the public static site, GitHub Pages deployment, Netlify headers/configuration, third-party assets loaded by the site, and the GitHub Actions used to build and deploy it.

Do not attempt destructive, disruptive, credential-theft, or unauthorized testing.
